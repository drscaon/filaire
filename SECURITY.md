# Security policy

Filaire generates files and runs local checks; it has no network service.
Security reports are still welcome, for example a generated file or an input
that makes the tool write outside its output folder or run unexpected code.

## Reporting a vulnerability

Please do not open a public issue. Write to
[contact@primvaria.com](mailto:contact@primvaria.com) with a description, the
version (`pip show filaire`) and the steps to reproduce. You will get an
answer within a week.

## Supported versions

Only the latest release on [PyPI](https://pypi.org/project/filaire/) receives
fixes.
